Checkboxes for execution tracking. Calendar sized from September 2026 pace (one major phase + UAT per focused week; sustainable = one such week every two weeks).

## Contract track (target: late January – early March 2027)

- [ ] **Oct–Nov 2026** — Vector memory (11.x) + semantic contradiction (7.1). Done when a spoken question retrieves a prior post or memory by meaning, and a contradiction is flagged beyond the same-key rule.
- [ ] **Nov–Dec 2026** — Typed HUD composer + cockpit collect with confirm. Done when a typed “weekly brief” uses the same agent path as PTT, and collect from the cockpit enqueues only after confirm.
- [ ] **Dec 2026–Jan 2027** — Phase 14 professional reports and charts. Done when a report opens as narrative plus charts, each labeled fixture / stale / live.
- [ ] **Jan–Feb 2027** — Phase 15 streaming speech. Done when sentence-chunked playback is the default live path. First-audio time is written down from a laptop run, or it is not claimed.
- [ ] **Feb–Mar 2027** — Operator auth + workspace boundary. Done when a second local user cannot read the first user’s snapshot.
- [ ] **Mar 2027** — Publish path + App Review packet (may continue into April). Done when a confirmed publish either posts under a permitted token or stops with honest “review pending.” No silent post.
- [ ] **After features** — Next 16 upgrade + full fixture-and-live rehearsal. Done when `verify` chain is green and the seminar story matches the screens.
